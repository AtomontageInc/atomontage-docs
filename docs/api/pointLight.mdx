### Color color {#Color-color}
Light color (alpha is ignored). Default white.

### number intensity {#number-intensity}
Brightness multiplier, >= 0. Default 1.

### number radius {#number-radius}
Range in meters; no light at and beyond it. Default 10.

### number inner {#number-inner}
Radius in meters up to which the light is at full intensity. Default 0.

### number falloff {#number-falloff}
Exponent of the fade between inner and radius: (1 - t)^falloff. 1 = linear, 2 = default, higher = faster drop near the inner radius.
