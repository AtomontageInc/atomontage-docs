### boolean effectOutline {#boolean-effectOutline}
If true, the `fx` domain-warp and reveal effects are applied to the shadow and outline passes as well, so the whole glyph warps together instead of the fill sliding off a static outline. Shape/shading (cornerRound, bevel) and pattern stay fill-only. Default false.

### table fx {#table-fx}
Grouped MTSDF text effects. Write-only: unlisted keys reset to default, so `fx = {...}` sets the complete warp state and `nil` clears all. Values are 0..1 unless noted. `cornerRound` rounds the glyph's sharp MSDF corners (1 = fully rounded, SDF-like). `bevel` is faux-3D bevel / emboss shading along the glyph edge, lit from `bevelLight` (direction, mapped to a 0..2pi azimuth). `melt` is an animated noise domain-warp ('melting') of the glyph; `glitch` static horizontal scanline-displacement bands; `bend` horizontal shear / slant; `twist` a swirl warp, stronger toward the glyph edges; `wave` an animated sine ripple along the glyph; `hollow` knocks out the fill. `reveal = { amount, mask='noise'|'linear'|'radial', param, edge }` is the coverage-mask reveal: `amount` 0 = solid, 1 = fully gone; `param` is the mask scale (noise) or angle (linear); `edge` is the hue of the glowing reveal front edge, 0 = no edge. `pattern = { kind='halftone'|'dither'|'contour', scale, angle }` is the procedural fill pattern: `scale` sets dot/cell size or ring frequency, `angle` its rotation mapped to 0..2pi. See the FX Playground editor tool.

### table fill {#table-fill}
Write-only 2-color fill gradient: `{ top=Color, bottom=Color, along='y'|'x' }`.

### table layers {#table-layers}
Array of stacked text layers, each `{ d=dilate, soft=glow, off=Vec2 shadow offset, color=, colorBottom=, along='y'|'x' }`. When set, the layer stack REPLACES the base fill/outline/shadow.
